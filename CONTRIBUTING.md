# CONTRIBUTING TO I-ECO-01

## Processo Bounty
Ogni issue ha una bounty in XMR. Al merge paghiamo.

## Struttura Repo
- `/robots` - Hardware Open (Fluffypony, Robot Barman)
- `/wallet` - XMR Tools (Wallet 1-Click, QR Generator)
- `/bots` - Bot Telegram (Flytek Bot, AI Translation)
- `/docs` - Guide TAZ (Onboarding, Sicurezza)
- `/design` - Brand Kit e Template (Anna Eva)
- `/contracts` - Smart Contracts (Welfare, DAO)

## Come Contribuire
1. Claima l'issue: `CLAIM #N`
2. Crea un branch: `solve-issue-N`
3. Fai una PR: `Solves #N`
4. Ricevi il bounty in XMR (entro 24h dal merge)

## Regole
- Codice Open Source
- XMR Only
- No gerarchie
- Trasparenza totale
