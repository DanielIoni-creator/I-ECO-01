## Come diventare un alieno MyZubster:

1. Vai su GitHub: https://github.com/DanielIoni-creator/I-ECO-01
2. Scegli un'issue con label `bounty` o `good-first-issue`
3. Commenta `CLAIM #N`
4. Scrivi il codice
5. Apri una PR
6. Ricevi XMR!
