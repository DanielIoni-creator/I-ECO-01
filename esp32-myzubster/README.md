# 🤖 MyZubster AI Companion

**ESP32 + Pytho AI = Personal AI Assistant**

## 📖 Descrizione

MyZubster AI Companion è un dispositivo basato su ESP32 che trasforma il chatbot Pytho in un assistente AI fisico con interfaccia vocale.

## 🎯 Caratteristiche

- 🔊 **Comandi Vocali**: Parla al dispositivo
- 🎤 **Microfono Integrato**: Ascolta i comandi
- 🔊 **Risposte Vocali**: Pytho ti risponde
- 🖥️ **Display OLED**: Mostra le risposte
- 🤖 **AI Integrata**: Pytho AI (MyZubster)

## 📦 Componenti

- ESP32 Dev Board
- OLED Display 128x64
- Microfono MAX9814
- Amplificatore PAM8302
- Altoparlante 8Ω 2W
- Pulsante
- Batteria 18650 + TP4056

## 🛠️ Installazione

1. **Carica il firmware** su ESP32
2. **Configura WiFi** e Gateway URL
3. **Collega** i componenti
4. **Accendi** e parla!

## 🔗 Collegamenti

- **Gateway**: http://localhost:3001
- **Portal**: http://localhost:3002
