## 🎯 什么是 MyZubster？

MyZubster 是一个开源生态系统，彻底改变了我们与自然互动的方式，结合了：

| 领域 | 描述 |
|------|------|
| 🌱 **植物学** | 使用AI进行植物注册和追踪 |
| 🤖 **机器人技术** | 具有视觉功能的自主园艺机器人 |
| 💰 **区块链** | MYZ和Monero (XMR)支付 |
| 🌐 **Web3** | 去中心化市场和NFT |

git clone https://github.com/DanielIoni-creator/I-ECO-01.git
cd I-ECO-01

# 2. 安装依赖
npm install

# 3. 启动网关 (端口 3001)
cd gateway
npm start

# 4. 启动门户 (端口 3002)
cd ../portal
npm start

# 5. 访问门户
